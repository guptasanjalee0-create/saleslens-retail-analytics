# SalesLens project overview

## Formal problem statement

Small retailers generate transaction-level sales records but may not have a straightforward way to turn those records into useful business insights. SalesLens is a beginner-scale retail analytics project that cleans historical transaction data, calculates descriptive sales metrics, stores the prepared records in a relational SQL database, and presents trends through charts and a simple dashboard.

## Objectives

1. Inspect transaction data and identify common data-quality issues.
2. Clean and prepare data using Python and Pandas.
3. Calculate revenue, order, product, country and customer metrics.
4. Use SQL to query and rank sales records.
5. Explore customers using simple Recency, Frequency and Monetary (RFM) features.
6. Communicate results using charts and a Streamlit dashboard.

## Scope

This is a descriptive analytics project. It does not forecast sales, prove why customers behave a certain way, or represent the current retail market. The included small sample is synthetic and exists only to make the code runnable immediately. The full UCI Online Retail dataset should be used before reporting real-world findings.

## Learning outcomes

- Python: variables, functions, data types, file input, exceptions and modules.
- Data analysis: tabular inspection, missing values, duplicates, filtering and grouping.
- SQL: SELECT, WHERE, GROUP BY, aggregate functions, CTEs and window functions.
- Visualisation: line charts and horizontal bar charts.
- Data interpretation: explain results, assumptions and limitations.
